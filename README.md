# 二维码选择器（Qrcode Selector）

左右下三区布局：上方左侧二维码卡片，上方右侧一级选项，下方二级选项，适配移动端（手机）。<u>桌面端和平板端需要优化</u>

二级选现记忆：每个分类独立记住上次选中内容，切走再切回自动恢复

静态本地页面，简约设计
