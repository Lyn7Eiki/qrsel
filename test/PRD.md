# 二维码选择器（Qrcode Selector）需求说明

## 一、项目概述

- 用纯网页技术（HTML / CSS / JavaScript）实现一个**二维码选择器**。
- 用途：从「分类 → 编码」数据库中快速选中某个二维码，界面展示该二维码、标题与内容，供扫码使用。
- 必须**适配手机端**。
- 页面整体**刚好塞满一屏**，自适应各类屏幕尺寸。

---

## 二、功能需求

### 1. 数据层

- 二维码数据库**暂时硬编码**，数据保存在代码中（`QR_DB` 变量）。
- 数据库内容**不在用户界面展示**。
- 数据结构为「分类 → 编码」两级：
  - 一级：分类（category）
  - 二级：该分类下的编码列表（items）
- 每个编码包含：
  - `code`（必填）：编码，同时是二维码扫码内容
  - `title`（可选）：自定义标题，不设置时自动生成
- **二维码内容必须与所选编码完全一致**。
  - 示例：选中 `D1212`，扫码内容就是 `D1212`
  - 不得添加多余内容（如"房间类D1212"、"二维码D1212"、"d1212"等均为错误）

### 2. 界面布局（左右下布局）

```
┌─────────────────────────────────────┐
│            Qrcode Selector          │  ← 顶部标题
├───────────────┬─────────────────────┤
│               │  一级选择列（分类）   │  ← 上方右侧
│   二维码卡片   │  · 房间             │
│   （左）       │  · 会议室           │
│               │  · 工位             │
├───────────────┴─────────────────────┤
│          二级选择行（编码）           │  ← 下方通栏
│  D1201  D1202  D1203  D1204  ...   │
└─────────────────────────────────────┘
```

- **上方左边**：二维码卡片
- **上方右边**：一级选择列（分类）
- **下方**：二级选择行（编码）
- 二维码卡片与一级选择列之间间距 **7px**

### 3. 二维码卡片（上中下结构）

```
┌─────────────────┐
│   二维码图片      │  ← 上：代码生成的二维码
├─────────────────┤
│   二维码标题      │  ← 中：见下方标题规则
├─────────────────┤
│   二维码内容      │  ← 下：所选编码
└─────────────────┘
```

- 二维码使用**代码生成**（qrcodejs 库）。
- **二维码标题规则**：
  - 编码设置了 `title` → 显示自定义标题
  - 未设置 `title` → 自动显示「分类名 + 序号」，序号从 1 开始按数组顺序排
  - 示例：`房间` 分类第 6 个编码 → 标题「房间6」；`D1212` 设置了 title → 标题「总经理办公室」

### 4. 一级选择列（分类）

- **最多显示 4 个分类**，超出部分滚动显示。
- 列宽较窄，**不显示项目序号数字**。
- **高度与二维码卡片对齐**，随卡片高度自适应。
- 选中项高亮显示。
- 点击分类时**不抢焦点**，避免浏览器自动滚动导致跳动。

### 5. 二级选择行（编码）

- 按编码平铺展示，**最多显示 3 行**，超出部分滚动显示。
- 选中项高亮显示。

### 6. 二级选择记忆功能

- 二级选择**有记忆**：每个分类独立记住上次选中的编码。
- 切换分类后再切回，恢复该分类之前选中的编码。
- 示例：选「钥匙4」→ 切到「货架」→ 切回「钥匙」→ 仍显示「钥匙4」。

### 7. 滚动条

- 滚动条**低调显示**：细（约 2px）、半透明、与内容保持一定间距。
- 内容溢出时显示滚动条。

## 四、数据格式说明

```js
var QR_DB = [
  {
    category: "房间",                      // 一级分类名（显示在右侧选择列）
    items: [                               // 该分类下的编码列表
      { code: "D1201" },                   // 最小字段：只有 code
      { code: "D1212", title: "总经理办公室" }  // 可选 title：自定义标题
    ]
  },
  {
    category: "设备",
    items: [
      { code: "EQ-01", title: "激光打印机" },
      { code: "EQ-02" }
    ]
  }
];
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `category` | 是 | 一级分类名，显示在右侧一级选择列 |
| `items` | 是 | 该分类下所有二维码编码的数组 |
| `code` | 是 | 编码，**同时是二维码扫码内容**（严格等于此值） |
| `title` | 否 | 自定义标题；不写时自动用「分类名 + 序号」 |

**一句话概括**：「分类」下挂「编码」，编码决定扫码内容，可选的 title 决定展示标题。
